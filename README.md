# Ancestral-Collection-
A must-have for browsing your own MTG collection. Unlike apps like ManaBox, Ancestral Collection is and always will be 100% free of ads and fees.


# Syntax
  Ancestral-Collection- uses a syntax similar to Scryfall. The main difference is the inversion commands.
  
  text and commands must be separated with a ":".
  
  inversion is a "!" before any command.
  
  oracle text is "o" followed by text.
  
  types are  "t" followed by text.
  
  
  mana symbols are "m" followed by the standard mana symbols.
  
  legality is "legal" followed by a format(auto completed) .
  
  Game changer status is "gc" followed by true or false.
  
  
  comparing numbers such as power, mana value, price, etc requires a operand(<=,>=,<,>,=).
  
  power is "pow".
  
  toughness is "tou".
  
  converted mana cost is "cmc".
  
  price is "usd".
